========================================================================
    PHẦN MỀM QUẢN LÝ QUÁN TẠP HÓA & MẶT HÀNG KHÁC (DESKTOP APP)
========================================================================

1. GIỚI THIỆU:
   Ứng dụng màn hình giao diện đồ họa (GUI) đơn giản, tiện lợi giúp bạn:
   - Quản lý danh mục hàng hóa (Thêm/Sửa/Xóa sản phẩm tạp hóa & mặt hàng khác).
   - Bán hàng trực tiếp, tự động trừ số lượng tồn kho theo thời gian thực.
   - Cảnh báo sản phẩm chạm ngưỡng sắp hết.
   - Xuất Báo Báo Doanh Thu, Tồn Kho ra file Excel (.xlsx).

2. YÊU CẦU HỆ THỐNG:
   - Máy tính đã cài đặt Python 3.8 trở lên.
   - Các thư viện Python cần thiết: pandas, openpyxl, tkinter (có sẵn).

3. CÁCH CÀI ĐẶT THƯ VIỆN (Nếu chưa có):
   Mở terminal / Command Prompt (CMD) và chạy lệnh:
   
   pip install pandas openpyxl

4. CÁCH CHẠY ỨNG DỤNG:
   - Cách 1: Bấm đúp chuột vào file `run_app.bat` (trên Windows).
   - Cách 2: Mở Terminal/CMD tại thư mục này và gõ lệnh:
     python main.py
